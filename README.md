# Angular-Apps smarter machen mit Generativer KI: Lokal und offlinefähig - Hands-on!

[BASTA! Mainz 2026](https://basta.net/ai-artificial-intelligence/angular-generative-ki-workshop/), 1. Oktober 2026, 09:00–16:30 Uhr

Trainer: Christian Liebel ([@christianliebel](https://x.com/christianliebel))

---

Generative KI ist in aller Munde: AI-gestützte Tools sind bereits zu integralen Bestandteilen unterschiedlicher Alltagsanwendungen geworden, Windows und Office eingeschlossen. Mit Transformers.js und der Prompt API bringen wir Generative KI auch in Ihre Angular-Anwendung: lokal und offlinefähig. Wir fügen einer TODO-Anwendung einen Chatbot hinzu und lassen Formulare sich ganz einfach selbst ausfüllen. Und Sie aktiv entwickeln mit! Wenn Sie mögen.

## Installationsanweisungen

Wenn Sie mitentwickeln möchten, bringen Sie bitte ein leistungsfähiges Gerät mit Windows oder macOS, eine aktuelle Version von Chrome, Node.js, einen Editor Ihrer Wahl und mindestens 20 GB freien Festplattenspeicher mit.

Idealerweise ist dies Ihr privates Gerät, da Gruppenrichtlinien oder Unternehmensproxys oft Probleme verursachen.

Nachdem Sie das Repository geklont haben, führen Sie bitte die folgenden Befehle in der Kommandozeile aus:

```sh
cd basta-2026-genai
npm i
```
